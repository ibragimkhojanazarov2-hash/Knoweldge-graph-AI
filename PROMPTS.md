# Marginalia — промпты до финальной версии

Как пользоваться: перед каждым шагом сделайте `/compact`, затем напишите Claude Code
одну строку — **«Выполни шаг N из PROMPTS.md»**. После шага проверьте результат
в браузере и только потом переходите к следующему.

Общие правила для всех шагов (Claude Code, прочитай их перед любым шагом):
- Работай только стандартной библиотекой Python и чистым HTML/CSS/JS — ставить пакеты нельзя.
- Все вызовы модели — только через `chat()` из `app/llm.py`.
- Не трогай `books/` и `data/` в git. Полный текст книг никогда не коммить.
- Сохраняй стиль макета: кремовая бумага / ночная библиотека, Times New Roman для текста,
  цвета связей: поддерживает — зелёный, противоречит — гранатовый, развивает — синий,
  пример — охра, то же самое — серый пунктир.
- После шага: проверь в headless-браузере на 1280, 820 (iPad) и 390 px (телефон),
  в светлой и тёмной теме, без ошибок в консоли.
- После любых изменений в `.py` всегда перезапускай сервер на 8000 в фоне
  (`nohup python3 app/server.py 8000 > /tmp/server.log 2>&1 &`) и проверяй, что новые
  адреса API отвечают: `curl` на страницу и на каждый новый `/api/...` должен дать 200,
  а не 404/500. Старый сервер останавливай по его PID.
- В каждом ответе давай ссылку только на порт 8000 и такую, которая открывается:
  `https://kitan-a.com/frp/s22/proxy/8000/#/...`. Перед ответом проверь, что сервер на 8000
  запущен (`curl` даёт 200) и что страница через прокси открывается без ошибок. Если сервер
  не запущен — запусти его в фоне (`nohup ... &`), а PID напиши студенту.
- В конце шага: `python3 app/export_demo.py`, коммит с понятным сообщением, `git push`.
  Покажи хэш коммита и коротко: что сделано, как проверить, что не сделано.

## Шаг 1. Доделать Этап 4 (по последнему ревью)
1. `extract.py`: пропускай служебные главы — титул, содержание, благодарности, об авторе,
   примечания, всё короче 1500 знаков. Удали уже извлечённые из них идеи и их связи.
2. «Связь дня»: обе цитаты, одна фраза «почему связаны», кнопка «Открыть на карте».
3. Карта на телефоне (< 700 px): книги друг под другом или подписи по касанию —
   никакого обрезанного текста.
4. Подзаголовок библиотеки: «Добавьте книги — Marginalia найдёт идеи и покажет,
   где авторы согласны и где спорят».

**Готово, когда:** в главах «Об авторе», «Благодарности» и т. п. ноль идей; «Связь дня» с цитатами;
карта на 390 px читается целиком.

## Шаг 2. Новые книги из общественного достояния
Скачай с ru.wikisource.org или imwerden.de в EPUB (только общественное достояние, русский язык):
«Размышления» Марка Аврелия и «Самодеятельность» Сэмюэла Смайлса.
Если скачать не выходит — скажи, я загружу файлы сам.
Загрузи в библиотеку и прогони: идеи → ключевые идеи → конспект → заголовки → связи.
Покажи: сколько идей у каждой книги, сколько связей по типам между каждой парой книг,
3 самых интересных противоречия.

**Готово, когда:** в библиотеке 4 книги, на карте связи между всеми парами.

## Шаг 3. Карта для 3+ книг
Сейчас карта рассчитана на две колонки. Для 3 и более книг:
- каждая книга — своя колонка или сектор по кругу, обложка сверху;
- переключатель «Сравнить две книги» → выбор пары → нынешний вид в две колонки;
- в общем виде по умолчанию только идеи со связями, порядок — чтобы линии меньше пересекались;
- касание идеи подсвечивает её связи во ВСЕХ книгах.

**Готово, когда:** 4 книги на одном экране читаются, режим «две книги» работает.

## Шаг 4. Автоматическая обработка при загрузке
После «Добавить книгу» книга сама проходит весь путь без ручных команд:
главы → идеи → ключевые идеи → конспект → заголовки → связи со всеми книгами.
- Обработка в фоне (отдельный поток или процесс), сервер не блокируется.
- На карточке и странице книги — прогресс: «Идеи: глава 5 из 16», «Связи: 2 из 3 книг».
- Можно загрузить несколько файлов сразу — они встают в очередь.
- Ошибка модели → до 3 повторов с паузой; если не вышло — статус «ошибка» и кнопка «Повторить».
- Счётчик запросов к API на книгу (чтобы видеть расход квоты).
- При извлечении модель ставит каждой идее 3–5 тем-тегов; поиск кандидатов связей
  учитывает и общие слова, и общие теги.

**Готово, когда:** загружаю EPUB → через несколько минут книга полностью готова, без терминала.

## Шаг 5. «Спросить библиотеку»
Новая вкладка «Спросить» в шапке.
1. Поиск: по вопросу отбери 12 самых подходящих идей с цитатами из всех книг
   (общие слова + теги + связи найденных идей). Без внешних библиотек.
2. Модель отвечает ТОЛЬКО по этим фрагментам, после каждой мысли — сноска [n].
   Если ответа в книгах нет — так и говорит.
3. Проверь кодом, что каждая сноска указывает на реальный фрагмент; лишние убери.
4. Под ответом — источники: книга, глава, цитата; клик открывает идею.
5. Три подсказки следующих вопросов. Пять примеров вопросов на пустом экране.
6. История вопросов сохраняется в базе.

**Готово, когда:** «Что мои книги говорят о неудачах?» даёт связный ответ из нескольких книг
со сносками, а «Как приготовить борщ?» — честное «в ваших книгах этого нет».

## Шаг 6. «Спор авторов»
Экран «Спор»: выбор двух книг (или двух авторов).
- Три блока: «Согласны», «Спорят», «Только у А / только у Б» — из связей и ключевых идей.
- AI-резюме 3–5 предложений: в чём суть разногласия и от чего зависит, кто прав.
- Результат кэшируется в базе, кнопка «Пересчитать».
- Ссылка на спор из страницы книги и из «Мостов».

**Готово, когда:** спор «Зелёный свет» ↔ «Размышления» читается как короткая статья.

## Шаг 7. Проверка связей пользователем
- В панели связи кнопки «Верно / Неверно / Изменить тип» сохраняются в базе (статус связи).
- «Неверно» — связь скрывается везде (карта, мосты, связь дня, спор), но не удаляется.
- Подтверждённые связи помечены значком ✓ и всегда показываются, даже при фильтре «сильные».
- На странице книги счётчик «проверено вами: 7 из 22».

**Готово, когда:** отклонённая связь пропадает отовсюду после обновления страницы.

## Шаг 8. Повторение (чтобы не забывать прочитанное)
Вкладка «Повторить».
- Каждый день 5–10 карточек из ключевых идей и подтверждённых связей:
  «Какую мысль доказывает эта цитата?», «Как связаны идея А и идея Б?»,
  «Кто из авторов не согласился бы с этим?».
- Сначала вопрос, по касанию — ответ с цитатой.
- Кнопки «Не помню / Трудно / Помню». Интервалы: 1 → 3 → 7 → 21 → 60 дней.
- На библиотеке плашка «Повторить: 6 карточек».

**Готово, когда:** карточки появляются и после ответа переносятся на правильную дату.

## Шаг 9. Поиск и навигация
- Поиск `⌘K` / кнопка «Поиск» в шапке: по идеям, цитатам, книгам, заметкам. Результаты сгруппированы.
- Выбор результата: идея → страница идеи, с кнопкой «Показать на карте».
- На карте поле поиска: подсвечивает найденные идеи.
- Кнопка «Назад» браузера работает на всех экранах.

## Шаг 10. Экспорт
Кнопка «Экспорт» в библиотеке:
- **Obsidian / Markdown:** zip-архив — файл на каждую книгу (конспект, ключевые идеи) и на каждую

- **Карта:** сохранить текущий вид как PNG/SVG.
- **Один спор или ответ «Спросить»:** скопировать как Markdown.

**Готово, когда:** архив открывается в Obsidian, и граф Obsidian показывает связи.

## Шаг 12. Надёжность
- Удаление книги (с подтверждением) удаляет её идеи, связи, заметки, обложку.
- Включи `PRAGMA foreign_keys = ON`; повторная загрузка той же книги — «уже в библиотеке».
- Понятные ошибки: битый EPUB, пустой файл, модель недоступна, нет сети.
- Медленные запросы — скелетоны загрузки вместо пустого экрана.
- Простые тесты на Python (`unittest`) для парсера EPUB, проверки цитат, парсинга ответов модели,
  связей; команда `python3 -m unittest`.

**Готово, когда:** все тесты зелёные, ни один сценарий не ломает страницу.
